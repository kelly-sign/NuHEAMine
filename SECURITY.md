# Security Policy

## Supported version

Security fixes are applied to the latest version on the default branch.

## Reporting a vulnerability

Please report a suspected vulnerability through GitHub's private vulnerability
reporting feature instead of opening a public issue. If that feature is not
available, contact the corresponding author through the private contact details
in the associated publication. Include affected endpoints, reproduction steps,
impact, and any proposed mitigation.

Never include production credentials, access tokens, database exports, or
personal research data in an issue or pull request.
